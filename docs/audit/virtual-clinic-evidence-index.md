## In-test verifications (not screenshot-based)

- **ZIP/bundle**: UAT-LAB-03/04 download the real bundle, unzip in-test,
  assert `prescription.pdf` non-empty, `manifest.json` members match zip
  entries, and an attached patient STL is present.
- **SHA-256**: UAT-ASSET-03 compares downloaded bytes with the generated
  fixture hash; fixtures are deterministic, produced in code
  (`fixtures.ts`), so provenance is by construction.
- **STL preview**: UAT-ASSET-02 diffs canvas pixels across
  orbit/zoom/reset — real WebGL interaction, not button smoke.
- **Idempotency**: UAT-NEG-03 issues same-tick double clicks and counts
  side effects.

## CI / large artifacts

Full Playwright traces, videos and the `web-audit-evidence` bundle are
uploaded as GitHub Actions artifacts on the `validate` workflow
(`playwright-report`, `web-audit-evidence`). The `.stl` blobs themselves
are never committed (CI forbids `*.stl`); they are regenerated per run.
