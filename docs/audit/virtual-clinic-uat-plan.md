# Virtual Clinic UAT — Plan

Scope: independent user-acceptance pass over EasyRS covering the intended
clinic→lab→delivery journey, mapped against *public* EasyRx workflow
documentation (clean-room: no private code, assets or undocumented behaviour
is copied). "厨房/技工室" in the task brief maps to the **Lab** role.

## One-command environment

```bash
docker compose -f infra/docker-compose.yml up -d --build
# schema + synthetic seed are run by the one-shot `migrate` service
# (SEED_SYNTHETIC=true). Re-run the seed any time with:
docker compose -f infra/docker-compose.yml run --rm -e SEED_SYNTHETIC=true migrate
```

Stack: PostgreSQL, Redis, RustFS (S3-compatible), FastAPI (`:8000`), Vite web
(`:5173`). No manual wiring is required.

## Synthetic dataset

`tests/e2e/uat/dataset.ts` creates six reusable patients idempotently
(`external_ref` = `UAT-P0x`, creation races tolerated):

- P01 Jordan Keeley — teen retainer, simplest happy path (upper+lower STL)
- P02 Milo Vargas — RPE expansion; required options + tooth ops
- P03 / P03B Casey Reyes ×2 — same name+DOB; duplicate-detection twin
- P04 Amara Osei — clinical communication (comments/approvals)
- P05 Noor Lindqvist — QC → ship → receive → deliver closure
- P06 Daniil Petrov — delete-protection subject

File fixtures are generated **in code** at runtime
(`tests/e2e/uat/fixtures.ts`) because the repo CI forbids `*.stl` blobs. Each
fixture is deterministic (fixed seed geometry), and every upload/download is
SHA-256 verified in-test against the generated bytes — provenance is by
construction, not by a recorded hash table.

## Run

```bash
cd apps/web
npx playwright test tests/e2e/uat/          # 49 UAT cases
npx playwright test tests/e2e/            # + 23 legacy browser regressions
node tests/e2e/uat/run-clinic-audit.mjs   # suite + evidence + screenshots
cd ../api && .venv/bin/pytest tests/      # backend
```

Evidence lands in `docs/audit/evidence/virtual-clinic/` (results.json,
summary.json/csv, page screenshots). API calls are used only to stage
preconditions; every asserted action is performed in the browser.
