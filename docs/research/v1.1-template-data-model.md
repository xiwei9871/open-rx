# V1.1 — Templates / Parts / Appliances data model (V-04 resolved)

Scope: structured catalog + parameter dictionary for S1b. All catalog artwork is EasyRS-owned
(clean-room: no EasyRx product images/names copied verbatim into seed data — we model our own
orthodontic vocabulary). `[SRCxx]` = audit IDs.

## Confirmed concepts → entities

| EasyRx concept | EasyRS entity | Evidence |
|---|---|---|

| Parts | `part` (component item; arch scope; anchor model; option dictionary ref) | CONFIRMED SRC01 |
| Appliances | `appliance` (composition header over parts) | CONFIRMED SRC01 |
| Per-lab custom parts | `part.owner_org_id` (custom catalog entries) | CONFIRMED SRC01/SRC33 |

## Schema sketch (S1b scope only; SQL naming consistent with existing modules)

```
catalog_part
  id, tenant_id, owner_org_id NULL(universal)|org, kind enum(part|appliance),
  code, display_name, category, default_arch enum(any|upper|lower),
  anchor_model enum(tooth|arch|area|points), editable_points int,
  option_dict_id NULL, active bool
  UNIQUE(tenant_id, owner_org_id, code)          -- universal + per-lab namespaces

option_lookup
  id, tenant_id, owner_org_id, name, values jsonb    -- shared lists (SRC36)

part_option_dict                                -- per-part parameter schema
  id, tenant_id, part_id → catalog_part, field_key, label,
  ui enum(select|toggle|number|text|color), required bool default false,
  lookup_id NULL → option_lookup, values jsonb NULL

product_class_option_set                        -- lab-configured form dictionaries
  id, tenant_id, lab_org_id, product_class enum(aligner|idb|resin|study_model),
  field_key, label, applies_to enum(upper|lower|both|na), options jsonb, active

rx_template
  id, tenant_id, owner_org_id, name, composition jsonb
    {parts:[{part_id,arch,anchor,position,options}], comments, annotations,
     acrylic:{...}, resets:{...}},
  source enum(practice_saved|lab_managed|lab_saved_for_practice),
  origin_rx_id NULL, active bool, version int

template_grant                                  -- Copy/Edit/View (SRC33)
  template_id → rx_template, grantee_org_id, level enum(copy|edit|view)
  UNIQUE(template_id, grantee_org_id); only owner_org manages grants

rx_part                                         -- instance on a live Rx
  rx_id → rx, seq, part_id → catalog_part, arch, anchor_teeth int[],
  anchor_points jsonb, position jsonb, options jsonb, notes

price_list + price_list_item + practice_price_tier
  price_list(tenant_id, lab_org_id, name, is_default)
  price_list_item(price_list_id, part_id NULL, product_class NULL,
                  field_key NULL, option_value NULL, unit_price numeric, currency)
  practice_price_tier(lab_org_id, practice_org_id, price_list_id)  -- ≤4 tiers (SRC16)
```

## Behavior rules (evidence → implementation)

1. Lab-scoped catalog: workspace resolves parts as `universal ∪ lab_owner parts`; missing
   aligner options ⇒ empty dropdown + free-text fallback (CONFIRMED SRC01/SRC25).
2. Part placement: `default_arch` restricts placement (e.g. upper-only retainer); anchor
   model determines tooth vs area vs N-point placement (CONFIRMED mechanics).
3. Part options are optional at submit (labs trained to ask) — `required=false` default
   keeps us honest; EasyRS MAY allow labs to mark options required (E, PROVISIONAL).
4. Template apply = copy composition into rx parts/comments/annotations; provenance fields
   (`source`, lab badge) drive UI marking (CONFIRMED SRC01/SRC33).
5. Shared-edit templates can be overwritten by grantees — CONFIRMED documented risk;
   EasyRS warns on edit for shared templates (UX parity, not copying).
6. Template permission edits restricted to owner org (CONFIRMED SRC33).
7. Price snapshot on submit: resolve practice tier → price list → items; store
   `rx.price_snapshot_json` + computed total; existing orders immune to later changes
   (CONFIRMED SRC18 snapshot semantics).
8. Resets/extractions/IPR block `N/A` for `form_type in (aligner,idb)` (CONFIRMED SRC02).
9. Universal-library Rx: parts resolved from universal namespace only; `submit` rejected
   until lab assigned (CONFIRMED SRC01).

## Open unknowns (stay UNKNOWN / PROVISIONAL)

- Exact part taxonomy (500+ names) — we will NOT reconstruct EasyRx's list; EasyRS seeds a
  small honest catalog (e.g. clasp, labial bow, RPE screw, band, retainer base) and lets labs
  define custom parts. UNKNOWN by policy.
- Per-part editable-point counts and true arch-rule matrix — UNKNOWN; schema supports it,
  data stays lab-configured.
- Template versioning/history — UNKNOWN; `version int` reserved PROVISIONAL.
- Template → price item linkage depth — PARTIAL (SRC34 price comparison confirmed).
