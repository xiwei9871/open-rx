# STL 人工编辑与加工 PoC 技术方案 V1.0

> **本轮仅设计与验收方法，不实现。** 对应任务书 §六、EPIC-07/08 的预备实验，以及主报告 §5.3 G3D 门控。
> 目标：用受控实验回答"哪套几何栈能在质量、速度、鲁棒性上支撑 EDIT-* / AI-005~012"，**禁止在 PoC 前宣称等价 EasyRx**。

## 1. 验证链

```
STL Upload → Validate → Preview → Orient → Trim → Base → Label → QC → Export
```

| 环节 | 研究问题 | 通过指标（初值，专家校准后冻结） |
|---|---|---|
| Upload | 二进制/ASCII 识别、单位与尺度推断 | 元数据报告正确（mm 推断置信度） |
| Validate | manifold、watertight、边界环、自交、退化面、法向一致、连通分量 | 缺陷注入检出率 100%；报告结构化可定位 |
| Preview | 大网格加载/旋转/缩放流畅度 | ≥50MB STL 首屏 <5s、交互 ≥30fps（开发机基准） |
| Orient | 三点定位+咬合位姿保持 | 变换可逆恒等误差 ~0；上下颌相对位姿偏差 <0.05mm(等效角) ? |
| Trim | 手绘曲线投射裁剪；凹面/开口/薄边界鲁棒性 | 样本集成功率 ≥95%；边界光滑无碎面；失败有分类 |
| Base | 实心/中空底座；高度/壁厚实测；布尔封合 | 实测与参数差 ≤0.1mm；结果 watertight；薄壁自交=0 |
| Label | 凹/凸字布尔；悬浮部件检测 | 字符连通无悬浮；切片可读性人工评级 |
| QC | 全量指标+体积变化+咬合校验 | verdict 规则一致；阻断正确 |
| Export | 输出 STL 与 provenance（参数+引擎版本+哈希） | 下游工具（切片器）可打开；溯源字段完整 |

**速度**：单环节处理 ≤60s（50MB 输入，参考硬件）；失败恢复：任何一步失败保留源+参数+错误分类，可重试/可转人工。

## 2. 技术选型对比（候选评估表）

| 维度 | Three.js（前端） | Trimesh（Py） | Open3D（Py/C++） | VTK（Py/C++） |
|---|---|---|---|---|
| 角色 | 预览+交互（必选） | 参考实现首选 | 点云/注册/采样强项 | 全能但最重 |
| 网格手术(裁剪/布尔/偏置) | 弱（仅交互辅助） | 中（bool 依赖后端 manifold3d/Blender） | 弱-中 | 强（vtkBoolean/vtkClip） |
| 网格检查/修复 | 弱 | 中 | 中 | 强 |
| 大模型性能 | LOD/分块可 | 纯 Python+numba 视操作 | C++ 核心快 | C++ 核心快 |
| 曲线投射到表面 | n/a（交互采集） | ray/proximity 可用 | kd-tree 可用 | 成熟 |
| 许可 | MIT | MIT | MIT | BSD |
| 风险 | 大内存模型 | 布尔稳健性 | 网格手术生态少 | 打包体积/复杂度 |

**方案**：前端 Three.js（交互采集：基准点、trim 曲线）；计算 worker 先用 **trimesh 参考实现**完成全链（能跑通即产出指标）；**并行**用 VTK 实现 Trim/Base/Label 三个重几何环节做对照。裁决标准见 §5。manifold3d 作为布尔备选库参与评估（许可 MIT）。

## 3. 测试集要求（G3D-03）

- **规模**：30–50 份已授权且脱敏的牙颌 STL；**按病例与扫描会话切分**，评估集不进调参循环。
- **覆盖矩阵**（每格 ≥3 样本）：上颌/下颌 × 完整/缺损边缘 × 含托槽/无托槽 × 好/中/差网格质量 × 常见坐标系差异（Z-up/Y-up、左右手系）。
- **缺陷注入集**：在好样本上程序化注入 — 破洞、自交、翻转法向、漂浮片、重复面、非均匀尺度 — 每类 ≥5 个。
- **存储**：样本库不入公开仓库（SAFE-008 红线）；登记 manifest（hash、来源授权、标签），CI 只跑合成 fixture。

## 4. 质量指标体系

| 组 | 指标 | 说明 |
|---|---|---|
| 有效性 | watertight、自交数、边界环、非流形边、连通分量 | 必须项 |
| 几何保真 | Hausdorff 距离（裁剪前后牙冠区）、体积差 %、咬合标记点位移 | 保形验收 |
| 参数一致 | base_height/wall_thickness/trim_margin 实测 vs 设定 | 卡尺式验收 |
| 可用性 | 处理时长、峰值内存、交互帧率 | 性能预算 |
| 鲁棒性 | 成功率、失败分类分布、重试恢复率 | 分类体系复用 G3D-01 |
| 实物 | 切片器可开、打印样件尺寸抽查 | G3D-05 实物验收 |

**公差基准由合作技工/临床专家定义后冻结（G3D-04）**——本文件中的数值均为工程初值。

## 5. 验收方法与裁决

1. **阶段 0（管线通）**：trimesh 参考实现跑通全链 5 个样本，产出结构化指标 JSON。
2. **阶段 1（对照）**：VTK 实现同环节跑同样本；输出两引擎对照表（质量×速度×失败分类）。
3. **阶段 2（边界）**：缺陷注入集 + 全样本集；两引擎对比卡：成功率、指标、失败可诊断性。
4. **阶段 3（实物）**：选 5 个产出切片打印；尺寸/贴合/标签可读性人工验收。
5. **裁决**：按加权（质量 40% > 鲁棒性 25% > 性能 20% > 生态/许可 15%）选主引擎；结果写 `docs/poc/results/` 并回写 ADR-0003。

**退出标准**：任何"可用于生产"的结论必须同时满足样本集指标达标 + 实物验收 + provenance 完整。**STL 预览好看 ≠ 生产合格**（主报告 §5.3）。

## 6. AI/自动线研发风险登记（不进本 PoC 交付）

| 线 | 依赖输入 | 主要风险 | 必需数据/授权 | 人工兜底 |
|---|---|---|---|---|
| ABS/自动裁剪底座（AI-005/008~012） | 样本集+recipe 参数 | 凹面边界推导、咬合保持 | 30–50 样本 + 专家公差 | 失败转人工编辑 |
| ABR 去托槽（AI-006） | 含托槽标注集 | 牙面重建偏差、过度磨除 | 标注训练/评估集（授权） | 100% 人工审阅放行 |
| AI Blockout（AI-007） | 倒凹/贴合区标注 | 干涉预期贴合 | 医工指标定义（专家） | 人工把关+干涉检查 |
| PTS 轨迹（AI-013/014） | 厂商设备协议 | 格式/坐标/法线未公开（GAP-13） | 厂商授权 + 设备测试样件 | 中间格式可视化审 |

四条线共同约束：**无已验证评估集与专家标准前，任何自动结果不进入临床生产链**；全部经 processing_job 溯源与 QA 门控。
